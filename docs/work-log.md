### 세부 내용

- **다국어 자막**: 자막 한 줄에 ko/en/ja/zh/zh-Hant 텍스트를 동시 보관하는 언어 트랙 구조 도입. YouTube CC 언어 트랙 우선 추출, Whisper 언어 힌트, 간체/번체 한자 자동 판별. 번역은 언어별 전용 프롬프트 + 방송 윤문/원문 충실 스타일.
- **자막 겹침 수정**: YouTube 플레이어 자체 CC 기본 숨김 토글 추가. YouTube 자동 자막의 큐 시간이 겹쳐 뒤 큐가 영영 표시되지 않던 버그를 큐 정리 로직과 "가장 최근 시작한 큐 우선 표시"로 해결. 짧게 끊긴 조각 자막을 앞 문장에 잇는 옵션 추가.
- **OpenClaw 연동**: TRANSLATE_PROVIDER=openclaw 시 twinverse-ai 게이트웨이(OpenAI 호환 API)로 번역, 실패 시 OpenAI GPT-4o 자동 대체. 번역을 비동기 잡(POST→202 jobId→폴링)으로 전환해 Orbitron 프록시 60초 타임아웃 회피.
- **운영 환경변수 누락 발견·복구**: 점검 중 운영 컨테이너에 DATABASE_URL 등이 전혀 주입되지 않은 것을 발견(Orbitron이 Dockerfile ENV를 제거). 대시보드 env_vars에 DATABASE_URL·OPENAI_API_KEY·YOUTUBE_API_KEY·AUTH_SECRET·OPENCLAW_TOKEN 등 주입, 재배포로 정상화 확인.
- **회원 등급 시스템**: User.role(USER/ADMIN)·plan(FREE/VIP)·disabled·개인 API 키(AES-256-GCM 암호화) 추가. 부트스트랩 관리자 자동 승격, JWT 콜백에서 매 요청 갱신. 일반 회원은 본인 키 등록 전까지 기능 화면 잠금. /dashboard/admin 회원 관리 UI.
- **yt-dlp 403 수정**: 운영 컨테이너의 Alpine 패키지 yt-dlp(2026.03.17)가 낡아 YouTube가 403으로 차단하는 것을 컨테이너 내 실측으로 확인. python3+media/bin/yt-dlp(최신 릴리스, 3일마다 자동 갱신) 방식으로 전환, 403/서명 오류 시 강제 갱신 후 재시도.
- **YouTube 검색 쿼터 소진 대응**: Data API search.list(100 units/회)가 일일 한도를 금방 소진하는 문제 발생. 검색 1단계를 yt-dlp 웹 검색(쿼터 0)으로 이전, 실패 키워드만 Data API 폴백. 수집 1회 쿼터 약 302→2 units로 절감.
- **공유 링크 + MP4 렌더링**: SubtitleShare 모델, /share/[token] 뷰어(비공개=로그인 회원 누구나, 공개=로그인 불필요). 렌더링은 Noto Sans CJK 폰트 자동 설치 → yt-dlp 원본 캐시 → ASS 변환 → ffmpeg libass 번인. 전역 큐 1개씩 순차 처리, Range 지원 다운로드. 운영 서버에서 3분25초 1080p 영상 렌더링 60초로 검증.
- **자막 위치·폭 개선**: overlayX/overlayY(%) 좌표를 세션·공유에 저장, D-pad 버튼과 포인터 드래그로 조정. 자막 상자 폭 80%→96%, 렌더링 여백 140px→30px. 긴 문장은 글자 크기 자동 축소(subtitleScale). 번역 프롬프트가 넣던 줄바꿈을 공백으로 정리해 짧은 문장이 불필요하게 두 줄로 나오던 문제 해결, 기존 세션용 "줄바꿈→한 줄" 일괄 정리 버튼 추가.
- 모든 배포는 GitHub main 푸시 → Orbitron 웹훅 자동 빌드로 진행, 각 기능마다 운영 서버에서 e2e 스크립트로 검증 완료.
